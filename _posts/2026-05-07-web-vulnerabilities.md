# 웹 보안 기초: SQL Injection, XSS, CSRF

웹 보안에서 자주 등장하는 대표적인 취약점에는 SQL Injection, XSS, CSRF가 있다.

이 세 가지는 이름은 다르지만 공통점이 있다.

> 원래는 데이터로 처리되어야 할 사용자 입력값이 코드나 권한처럼 잘못 해석될 때 문제가 발생한다.

## SQL Injection이란?

SQL Injection은 사용자가 입력한 값이 SQL 쿼리의 일부로 잘못 처리될 때 발생하는 취약점이다.

예를 들어 로그인 기능에서 아이디와 비밀번호를 검사할 때, 입력값을 안전하게 처리하지 않으면 공격자가 SQL 문법을 끼워 넣어 인증을 우회할 수 있다.

## XSS란?

XSS는 Cross-Site Scripting의 약자이다.

웹사이트가 사용자의 입력값을 제대로 검증하지 않고 페이지에 출력할 때 발생할 수 있다.

공격자는 스크립트 코드를 삽입해 다른 사용자의 브라우저에서 악성 스크립트를 실행시킬 수 있다.

## CSRF란?

CSRF는 Cross-Site Request Forgery의 약자이다.

사용자가 로그인된 상태를 악용해, 사용자의 의도와 상관없이 특정 요청을 보내게 만드는 공격이다.

예를 들어 사용자가 로그인된 상태에서 악성 링크를 클릭하면, 사용자가 직접 요청한 것처럼 서버에 요청이 전달될 수 있다.

## 정리

SQL Injection, XSS, CSRF는 웹 보안 공부에서 자주 등장하는 기본 취약점이다.

아직 깊게 이해한 것은 아니지만, 앞으로 각 취약점이 발생하는 원리와 방어 방법을 하나씩 정리해볼 예정이다.
